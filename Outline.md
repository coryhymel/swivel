\# Goal  
I want to create a windows application that’s basically a wrapper for gmail, gcal, and gdrive. The reason is that I need to be able to quickly switch between gmail and gcal for multiple different google accounts. This app will only be used by me and the overall goal is to help increase my productivity while not having to have multiple browser windows open.
